# Лабораторная работа №1 — «Как я провёл лето»

Этот проект представляет собой статический веб-сайт с адаптивной вёрсткой на Bootstrap 5.

## 🛠 Технологии
* HTML5 / CSS3 / SCSS
* Bootstrap 5
* JavaScript (ES6+)

## 🚀 Как запустить проект
1. Склонируйте репозиторий: `git clone <ссылка_на_репозиторий>`
2. Откройте файл `index.html` в вашем браузере.
